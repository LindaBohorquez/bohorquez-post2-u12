# ADR-002: Spring Data JPA con H2 para persistencia local

## Estado

Aceptado - 2026-06-01

## Contexto

El proyecto necesita persistir productos durante la ejecucion y permitir pruebas rapidas en un entorno academico. Configurar una base de datos externa agregaria friccion para ejecutar el laboratorio en distintos equipos.

## Decision

Se usa Spring Data JPA para implementar el repositorio de productos y H2 en memoria como base de datos local. `ProductoRepository` extiende `JpaRepository`, lo que reduce codigo repetitivo para operaciones CRUD y permite concentrar las pruebas unitarias en la logica de servicio.

## Consecuencias

Positivas:

- El proyecto se ejecuta sin instalar una base de datos adicional.
- Las operaciones CRUD basicas quedan cubiertas por Spring Data JPA.
- El repositorio mantiene una interfaz pequena y facil de validar con ArchUnit.

Negativas:

- H2 no reproduce exactamente el comportamiento de motores productivos como PostgreSQL o MySQL.
- La facilidad de `JpaRepository` puede ocultar consultas costosas si el dominio crece sin pruebas de integracion.
